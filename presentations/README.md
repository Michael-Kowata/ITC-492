# Presentations

Plan proposal (weeks 1-2), progress (weeks 7-8), and final (weeks 13-14)
presentations. Confirm actual dates with the course calendar.

Create a directory per talk containing its outline or slides and a README
recording date, audience, demonstrated commit, repository navigation order,
questions received, and follow-up issues.

## Talk Checklist

- Explain the problem, current milestone, and evidence of progress.
- Keep the repository open during the presentation.
- Show relevant issues, milestone dates, commits and their recorded checks.
- Open the weekly log, design, experiment evidence, or results as appropriate.
- Demonstrate implemented behavior using a rehearsed scenario.
- Record feedback and create follow-up issues with milestones.
