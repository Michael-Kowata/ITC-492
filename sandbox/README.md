# Technology Experiments

Create one directory per technology actually evaluated, for example
`sandbox/<technology-name>/`. Copy `_template/README.md` into it and keep the
trial code, dependency instructions, and small sanitized evidence alongside it.
The template is not a completed experiment.

Every experiment must explain what it showed and whether the technology was
selected. Link the relevant issue and design decision.

- [Google Forms/Sheets integration](google-forms-integration/README.md): isolated
  two-student M2 trial; owner confirmed copying, naming, destination, isolated
  responses, passing template diagnostics, and signed-out/external-account access.
  Cleanup and full settings checks remain.
